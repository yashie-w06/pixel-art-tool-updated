Build a complete, polished pixel-art editor in the current workspace. Prepare it for GitHub Pages, but DO NOT push, deploy, create a remote repository, or publish anything.

Stack:
- React + TypeScript + Vite
- HTML Canvas 2D for rendering
- Zustand for editor/UI state
- react-colorful for color picking
- IndexedDB through idb-keyval for autosave
- CSS Modules; responsive layout
- Vitest + Playwright for focused tests
- Use pnpm

Features:
1. New artwork: grid presets 16×16, 32×32, 64×64, plus custom width/height from 1–256 pixels. Default 32×32. Confirm before replacing unsaved artwork.
2. Pencil: click individual cells or hold and drag to paint continuously. Interpolate between pointer positions so fast strokes leave no gaps.
3. Eraser: clear pixels to transparency.
4. Fill bucket: fill connected pixels of the same color.
5. Eyedropper: pick an existing pixel’s color.
6. Color controls: visual picker, editable HEX input, recent colors, saved custom palettes.
7. Undo/redo: each completed drag is ONE action. Include fill, erase and clear operations. Bound history memory.
8. Zoom in/out, zoom percentage, pan, reset view and fit-to-view. Zoom must preserve artwork dimensions and sharp pixel edges.
9. Toggle grid visibility; show transparency using a checkerboard.
10. Autosave completed edits with debounce; restore the last project after reload. Display saving/saved/error status.
11. PNG download: transparent or chosen background; original size or 2×/4×/8× scaling. Exclude grid, checkerboard and editor overlays. Disable smoothing.
12. Download/reopen editable, versioned JSON projects containing dimensions, pixel data and palettes. Validate imported files and handle malformed/oversized files gracefully.
13. Mouse, touch and pen support. Provide an explicit pan tool for touch.
14. Keyboard shortcuts: pencil B, eraser E, fill F, eyedropper I, undo Ctrl/Cmd+Z, redo Ctrl/Cmd+Shift+Z, zoom +/−, hold Space to pan. Do not intercept shortcuts while typing in inputs.
15. Clear canvas with confirmation.
